# 常驻与自动恢复

目标：登录后自动托管监控进程；通过 Dock 正常启动应用时自动带上本地调试参数；应用关闭期间等待，不强制重开。

方案：两个用户级 LaunchAgent 分别托管 Python 采集服务和 Node 注入器。安装稳定的运行副本与独立启动器，将已有 Dock 应用入口指向启动器。启动器仅负责携带参数启动真实应用，不修改原应用文件。

限制：直接从 Finder、Spotlight 或原始应用路径启动原应用，可能不带调试参数；后台进程不能为已启动应用补加启动参数，也不会为此强制终止应用。Dock 入口是本次承诺的自动启动路径。

实施顺序：先验证 LaunchAgent 配置与 Dock 可逆变换；实现持久连接、安装与卸载；安装到本机；验证进程退出后恢复和调试端口暂时离线后重连；推送分支并创建 PR。

验收：完整现有测试通过；登录代理已加载；杀掉插件子进程后自动恢复；离线后能重连；Dock 入口指向启动器且其它条目不变；卸载可恢复原入口。当前运行的业务聊天不被退出。
